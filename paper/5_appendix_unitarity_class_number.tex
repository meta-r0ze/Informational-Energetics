\section{Unitarity and the Class Number}
\label{app:unitarity-class-number}

\begin{theorem}
Let $\mathbb{C}/\Lambda$ be a complex torus with complex multiplication by an order $\mathcal{O}$ in an imaginary quadratic field. Causal history on this torus is uniquely reconstructable from local data if and only if the class number $h(\mathcal{O}) = 1$.
\end{theorem}

\begin{proof}
Isomorphism classes of complex tori with endomorphism ring exactly $\mathcal{O}$ are parameterized by the ideal class group $\operatorname{Pic}(\mathcal{O})$, whose cardinality is $h(\mathcal{O})$.

If $h(\mathcal{O}) > 1$, there exist non-isomorphic tori sharing the same endomorphism ring $\mathcal{O}$. Local measurements restricted to endomorphic structure cannot distinguish between these distinct global states, resulting in \textbf{Causal Degeneracy}: distinct global histories yield identical local signatures, violating unitary evolution.

If $h(\mathcal{O}) = 1$, all fractional ideals are principal and the class group is trivial. Up to isomorphism, there exists exactly one torus with endomorphism ring $\mathcal{O}$. Consequently, local data uniquely specifies the global history, satisfying unitarity.
\end{proof}
